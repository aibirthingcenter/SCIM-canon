## Module Documentation

### Federal Operations Tracker

Tracks federal operations across multiple cities with comprehensive documentation.

**Key Methods:**
- `register_operation()`: Register new federal operation
- `add_verified_fact()`: Add verified fact to operation
- `add_unverified_claim()`: Track unverified claims
- `detect_pattern()`: Register detected patterns
- `get_operation_report()`: Generate operation report
- `export_to_json()`: Export data to JSON

### Verification Defender

Implements "Defenders of Greater Library" standard for claim verification.

**Verification Tiers:**
- **Tier 1**: AP, Reuters, AFP, Bloomberg, WSJ

**Key Methods:**
- `verify_claim()`: Verify claim with sources
- `disprove_claim()`: Disprove claim with evidence
- `get_verification_report()`: Generate verification statistics
- `export_verified_claims()`: Export verified/disproved claims
